# ResearchPR

## Progressive Web App

Build and deploy the app over HTTPS to enable installation. Supported browsers show an **Install app** action; on iPhone and iPad, use **How to install** and follow the Safari Home Screen steps.

The service worker provides an offline app shell and caches same-origin static assets after they are requested. Supabase requests and household data are not cached, so viewing or editing account data still requires a connection.
